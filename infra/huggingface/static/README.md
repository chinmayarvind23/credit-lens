# CreditLens recorded synthetic API examples

This free static preview presents five real responses captured from the local CreditLens synthetic API: DSCR threshold, exception, missing debt evidence, conflicting sources, and private-topic abstention. Choose an example and inspect its citations, saved source responses, and recorded execution trace.

**This is a recorded preview.** It has no live query backend, sign-in, document upload, or arbitrary question processing. The static viewer does not enforce or prove live authorization. Borrowers and policy pages are synthetic. Local financial dispositions assess DSCR only; lending decisions remain human-controlled.

The capture file preserves the exact UTF-8 query and response bodies, SHA-256 hashes, source GET responses, capture time, API source revision, and local runtime image identity. The browser verifies body hashes and cited source consistency before displaying an example.

The published package contains only prebuilt HTML, CSS, JavaScript, these intentional public synthetic examples, and their provenance manifest. No credentials, private plans, broader evaluation output, databases, source PDFs, or backend runtime are uploaded. No paid compute, storage upgrade, subscription, or inference service is configured.
