# ADR-005: Consistency and Durability by Data Class

## Status

Accepted.

## Strong/current semantics

Require for authorization, borrower values used in calculations, policy effective-date resolution, and durable audit records.

## Eventual consistency

Accept for search refresh, dashboards, and derived aggregate metrics.

## Durable data

Source documents, document versions, approved structured data, audit events, gold evals, benchmark artifacts.

## Rebuildable data

Embeddings, indexes, caches, temporary OCR artifacts.
